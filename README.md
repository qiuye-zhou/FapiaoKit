# FapiaoKit

一款基于 Electron 的差旅发票整理工具。选择发票 PDF 的文件夹，FapiaoKit 会自动解析发票内容、识别类型与金额、配对网约车行程单，并在你核对之后批量重命名文件、按模板生成 Excel 报销单。

## 功能特性

- **PDF 自动解析**：本地读取 PDF 文本层，无需联网、不上传任何票据。
- **多类型识别**：高铁票、机票 / 代订机票、住宿费、网约车、高速通行费、快递费，其余自动归入「其他」。
- **滴滴等行程单配对**：发票与行程单按金额自动匹配，日期取自行程单，生成报销单时一并归档。
- **人工核对表格**：低置信度记录高亮标记，日期 / 金额 / 报销内容均可直接编辑，金额合计实时更新。
- **PDF 预览填充**：内置 pdf.js 预览弹窗，选中票据上的文字即可填充到对应行，扫描件也能快速录入。
- **批量重命名**：按 `序号-报销内容-月.日-金额.pdf` 统一命名，先改临时名再改目标名，避免循环冲突。
- **生成报销单**：基于 `static/expense-template.xlsx` 模板写入明细、日期、项目类别与附件张数。
- **文件夹归档**：可选把整个文件夹重命名为 `项目简写 + 行程起止`，例如 `武汉青山船厂9.28-9.29`。
- **可重复整理**：已按规范命名的文件再次扫描时，会回读人工填写过的内容与金额。

## 支持的票据类型

| 类型 | 识别依据 | 报销内容示例 |
| --- | --- | --- |
| 高铁 | 铁路电子客票 | `上海-南京高铁`、`上海-南京退票费` |
| 飞机 | 电子客票行程单、代订机票 | `武汉-深圳飞机`、`机票` |
| 住宿 | 住宿服务 / 酒店名称 | `武汉住宿费` |
| 打车 | 客运服务费发票 + 行程单 | `打车` |
| 高速 | 通行费发票 | `高速费` |
| 快递 | 收派服务 / 快递费 | `快递费` |
| 其他 | 未能识别或扫描件 | 原文件名，需手动补全 |

默认行序为：高铁 → 飞机 → 住宿 → 打车 → 高速 → 快递 → 其他，同类型内按文件名排序；你也可以在表格中上移 / 下移调整。

## 使用流程

1. **选择出差文件夹**：点击「选择文件夹」，自动解析目录下所有 `.pdf`。
2. **核对发票**：检查类型、报销内容、日期、金额。黄色行表示需要人工确认，可点「🔍」打开 PDF，选中文字后右键填充到当前行。
3. **填写报销信息**：项目类别、船厂简写、行程起止日期、报销日期、报销单文件名，以及是否重命名文件夹。
4. **开始整理**：重命名 PDF、生成报销单并归档文件夹，完成后可直接打开结果目录。

> 日期列支持 `9.28`、`2026.9.28`、`2026-09-28` 等写法；省略年份时使用「票据统一年份」。所有发票日期必须落在该年份内，跨年请分批整理。

## 文件命名与报销单

- 发票：`{序号:02d}-{报销内容}-{月.日}-{金额}.pdf`，如 `01-上海-南京高铁-9.18-162.pdf`
- 行程单：在同一发票名后追加 `-行程单`，如 `08-打车-9.10-138.8-行程单.pdf`
- 报销单：默认按 `{项目简写}{MM.DD-MM.DD}.xlsx` 命名
- 模板约定：数据区为第 8–57 行（最多 50 条）；`F4` 写项目类别，`G4` 写报销日期，`R6` 写附单据张数

## 环境要求

- Node.js >= 20.19（Vite 7 要求）
- pnpm（仓库提供 `pnpm-lock.yaml`，且 `.npmrc` 固定 `node-linker=hoisted`，请勿改用 npm 的默认布局）
- Windows 打包需可访问 Electron 二进制源，脚本已配置 npmmirror 镜像

## 已知限制

- 仅处理**有文本层**的 PDF；纯扫描件（图片型 PDF）无法自动识别，需手动填写内容、日期与金额。
- 单次最多整理 50 条发票记录，超出请分批。
- 模板字段位置固定（`F4` / `G4` / `R6` / 数据区第 8 行起），更换模板时需同步调整 `organizeService.ts`。
- 重命名与写表在原文件夹内完成，操作前建议先备份原始票据。
