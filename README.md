# FapiaoKit

> 基于 Electron 的差旅发票整理工具：自动解析 PDF 发票、识别类型与金额、批量重命名并生成 Excel 报销单

## 功能特性

- **PDF 自动解析**：本地读取 PDF 文本层，**全程离线**，不会上传任何票据。
- **多类型自动识别**：高铁票、机票 / 代订机票、住宿费、网约车、高速通行费、快递费，其余归入「其他」。
- **网约车行程单配对**：按金额自动匹配，日期取自行程单，生成报销单时一并归档。
- **表格内直接编辑**：类型下拉切换、原生日期选择器、金额实时合计。低置信度记录高亮标记。
- **PDF 预览 + 选中填充**：内置 pdf.js 预览弹窗，在票据上选中文字即可右键填充到对应行；扫描件也能快速录入。
- **自定义条目**：除了识别出的发票，还能手动添加一行补贴（如「差旅补贴 ¥300 备注：按天补贴」），直接写入报销单。
- **批量安全重命名**：先写临时名再改目标名，避免同名 / 循环冲突。
- **Excel 报销单生成**：基于 `static/expense-template.xlsx` 模板写入明细、日期、项目类别与附件张数。
- **文件夹归档**：可选把整个出差文件夹重命名为 `项目简写 + 行程起止`（如 `武汉青山船厂9.28-9.29`）。
- **可重复整理**：已按规范命名的文件再次扫描时，会回读你之前人工填写过的报销内容与金额。

## 支持的票据类型

| 类型     | 识别依据                         | 报销内容示例              |
| -------- | -------------------------------- | ------------------------- |
| 高铁     | 铁路电子客票                     | `上海-南京高铁`、`退票费` |
| 飞机     | 电子客票行程单、代订机票         | `武汉-深圳飞机`、`机票`   |
| 住宿     | 住宿服务 / 酒店名称              | `武汉住宿费`              |
| 打车     | 客运服务费发票 + 行程单          | `打车`                    |
| 高速     | 通行费发票                       | `高速费`                  |
| 快递     | 收派服务 / 快递费                | `快递费`                  |
| 其他     | 未能识别或扫描件                 | 原文件名，需手动补全      |

默认排序：**高铁 → 飞机 → 住宿 → 打车 → 高速 → 快递 → 其他**，同类型内按文件名排序；也可以在表格里点 ↑ / ↓ 手动调整。

## 快速开始

### 环境要求

- **Node.js** ≥ 20.19（Vite 7 要求）
- **pnpm**（仓库固定使用，`.npmrc` 指定 `node-linker=hoisted`，Electron / electron-builder 需要扁平依赖结构）
- **Windows** 打包需可访问 Electron 二进制源，脚本已配置 npmmirror 镜像

### 安装与运行

```bash
# 安装依赖
pnpm install

# 开发模式（Vite dev server + Electron）
pnpm electron:dev

# 仅启动前端开发服务器（可独立访问 http://localhost:5173）
pnpm dev
```

### 构建与打包

```bash
# 构建前端产物
pnpm build:web

# 编译 Electron 主进程
pnpm build:electron

# Windows 打包（NSIS 安装包，输出到 release/）
pnpm build:win
```

## 使用流程

1. **选择出差文件夹**：点击「选择文件夹」，自动解析目录下所有 `.pdf`。
2. **核对发票表格**：
   - 类型列可直接下拉切换
   - 日期列使用原生日期选择器，也可手动输入 `YYYY-MM-DD`
   - 点「🔍」打开 PDF，在票据上选中文字后右键填充到当前行
3. **（可选）添加自定义条目**：点击「＋自定义条目 → 添加一条」，填写名称、金额、备注；不关联 PDF，只写入报销单。
4. **填写报销信息**：项目类别、项目简写、行程起止、报销日期、报销单文件名、是否重命名文件夹。
5. **开始整理**：重命名 PDF、生成报销单并归档文件夹；完成后可直接打开结果目录。

> 日期统一使用 `YYYY-MM-DD`。所有发票日期必须落在同一年份，跨年请分批整理。

## 文件命名与报销单格式

- 发票：`{序号:02d}-{报销内容}-{月.日}-{金额}.pdf`
  - 例：`01-上海-南京高铁-9.18-162.pdf`
- 行程单：在同一发票名后追加 `-行程单`
  - 例：`08-打车-9.10-138.8-行程单.pdf`
- 报销单：默认按 `{项目简写}{MM.DD-MM.DD}.xlsx` 命名
- 模板约定（`static/expense-template.xlsx`）：
  - 数据区：第 **8–57 行**，最多 50 条
  - `F4` 写项目类别，`G4` 写报销日期，`R6` 写附单据张数
  - 自定义条目只写 **F（名称）、H（金额）、Q（备注）**，无发生日期

## 已知限制

- 仅处理**有文本层**的 PDF；纯扫描件（图片型 PDF）无法自动识别，需手动填写。
- 单次最多整理 50 条发票记录（含自定义条目），超出请分批。
- 模板字段位置固定（`F4` / `G4` / `R6` / 数据区第 8 行起），更换模板时需同步调整 `organizeService.ts`。
- 重命名与写表在原文件夹内完成，**操作前请先备份原始票据**。
